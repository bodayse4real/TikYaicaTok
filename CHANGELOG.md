# TikYaicaTok Changelog

## [2.1.0] - 2026-11-08

### 🎮 Добавлено
- **Flappy TikTok** - встроенная мини-игра для офлайн режима
  - Автоматически появляется при отсутствии интернета
  - Простая механика: тапайте чтобы прыгать
  - Система сохранения рекордов
  - Переключатель в настройках мода
  - Достижения и системы уровней мастерства

- **Офлайн игра (раздел в настройках)**
  - Включение/отключение игры
  - Автоматический запуск при потере интернета
  - Детальное описание игры

- **Easter Eggs (Пасхалки)**
  - 15+ забавных сообщений в дневнике мода
  - Случайные сообщения достижений в игре
  - Ежедневные версии (easter egg в строке версии)
  - Developer mode пасхалки

- **Новые Java классы:**
  - `OfflineGame.java` - Game loop с SurfaceView
  - `OfflineGameActivity.java` - Activity для отображения
  - `OfflineGameSettings.java` - Управление настройками
  - `EasterEggs.java` - Забавные сообщения

### 🗑️ Удалено
- Ссылки на TilkaYo из благодарностей
- "someone's mf" благодарность заменена на "Offline Game"

### 📝 Изменено
- Благодарность Claude обновлена на "Claude Opus 5.5"
- Добавлены текстовые константы для новых настроек в `Text.java`
- Раздел "Благодарности" переорганизован
- Версия обновлена с 2.0.5 на 2.1.0

### 🎨 Внешний вид
- Новый раздел настроек "Офлайн игра" с иконкой игры
- TikTok розовая цветовая схема для Flappy TikTok (#FE2C55)
- Чёрный фон для лучшей видимости и батареи

### ⚙️ Технические детали
- Используется SurfaceView для оптимальной производительности
- Game loop работает на отдельном потоке (60 FPS)
- Безопасное сохранение high score в SharedPreferences
- Проверка интернета встроена в OfflineGameActivity
- Полная поддержка pause/resume

### 📚 Документация
- `OFFLINE-GAME-README.md` - Полное описание офлайн-игры
- Встроенная справка в настройках
