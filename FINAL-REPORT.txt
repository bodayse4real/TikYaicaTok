🎮 ГЛАВНАЯ ФИШКА: FLAPPY TIKTOK

Встроенная мини-игра для офлайн режима TikTok!

ВОЗМОЖНОСТИ:
✨ Автоматически появляется при отсутствии интернета
✨ Простая механика: тапайте чтобы прыгать
✨ Система препятствий (белые трубы)
✨ Счет и система достижений
✨ Сохранение высшего результата (high score)
✨ 60 FPS оптимизированная графика
✨ Полная интеграция в TikTok

КАК ВКЛЮЧИТЬ:
1. TikTok → Настройки и конфиденциальность → TikYaicaTok
2. Раздел "Офлайн игра"
3. Включить "Flappy TikTok"
4. (Опционально) "Показывать при отсутствии интернета"

КАК ИГРАТЬ:
- Отключите интернет (режим самолёта)
- Откройте TikTok
- Тапайте по экрану → прыгает
- Избегайте белых труб
- Каждый проход = +1 очко
- Упали/столкнулись = Game Over

ДОСТИЖЕНИЯ:
🏆 LEGENDARY PLAYER (1000+ очков)
🎮 EXPERT PLAYER (500+ очков)
💪 ADVANCED PLAYER (100+ очков)
👍 INTERMEDIATE PLAYER (50+ очков)
🚀 BEGINNER PLAYER (20+ очков)
👶 FIRST STEPS (10+ очков)

🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

✅ arm64 только (как и весь мод)
✅ Безопасное обращение к памяти

🚀 БЫСТРЫЙ СТАРТ

1️⃣ СБОРКА МОДА:
   ```
   python3 -m margyt /path/to/tiktok.apk -o build/TikYaicaTok-2.1.0.apk
   ```

2️⃣ УСТАНОВКА:
   ```
   adb install build/TikYaicaTok-2.1.0.apk
   ```

3️⃣ ВКЛЮЧЕНИЕ ИГРЫ В TikTok:
   Настройки → TikYaicaTok → Офлайн игра → Flappy TikTok (включить)

4️⃣ ИГРА:
   - Режим самолёта или отключить WiFi
   - Откройте TikTok
   - Играйте в Flappy TikTok! 🎮
